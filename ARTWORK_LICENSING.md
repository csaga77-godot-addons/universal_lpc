# Universal LPC Artwork Licensing And Attribution

The generated spritesheets under `resources/spritesheets/` are derived from artwork in the [Universal LPC Spritesheet Character Generator](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator).

Each source asset has its own authors, source URLs, and one or more available licenses. [`CREDITS.csv`](CREDITS.csv), copied from the upstream generator at the time this repository was published, is the authoritative attribution index for the included artwork.

When redistributing the spritesheets:

1. Preserve `CREDITS.csv`, or replace it with a complete attribution list covering every asset you distribute.
2. Make the credits reasonably discoverable to users.
3. Select and comply with one of the licenses available for each source asset, including attribution, share-alike, source-distribution, and anti-DRM terms where applicable.
4. Recheck upstream credits whenever generated spritesheets are refreshed from a newer generator checkout.

Licenses represented in the upstream credits include CC0, CC BY, CC BY-SA, OGA-BY, and GPL variants. Refer to the exact version and source links recorded for each row in `CREDITS.csv`, and consult the upstream project's [licensing guidance](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator#licensing-and-attribution-credits).

This artwork notice does not grant a license for the plugin's original GDScript code. No repository-level code license has been selected yet.
